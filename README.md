## Описание программы

Программа представляет собой консольное приложение для проверки надежности
паролей. Она анализирует введенный пользователем пароль на наличие цифр,
заглавных букв и специальных символов, после чего выдает вердикт о его
надежности и дает рекомендации по улучшению.

## Необходимые условия

Что нужно для установки программного обеспечения и как его установить:

1. Компьютер.
2. Git.
3. Python 3.10+.

> [!NOTE]
> Так как эту программу писал я, вам придется проверять пароли на человеке, перед началом использования.

Вот пример кода, который лежит в основе программы:
```python
def check_password_strength(password):
    if len(password) < 8:
        print("Пароль слишком короткий! Нужно минимум 8 символов.")
        return
    elif not re.search(r"\d", password):
        print("Добавьте хотя бы одну цифру.")
    elif not re.search(r"[A-Z]", password):
        print("Добавьте хотя бы одну заглавную букву.")
    else:
        print("Отличный пароль!")
```
> [!WARNING]
> Программа не проверяет, не забыли ли вы пароль — она верна вам не спасет.
> Используйте осторожно!
